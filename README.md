# Zapin-India
Zapin Hotel Online Billing (RBA) 

“One of the key projects I worked on is the ‘Zapin Hotel Billing System,’ a full-stack, role-based web application designed to streamline hotel food ordering, billing, and delivery operations.

On the frontend, I used HTML, CSS, JavaScript, and React.js to build a fully responsive and user-friendly interface, developed using Visual Studio Code. The backend was implemented using Core Java with the Spring Boot framework. We managed dependencies using Spring Initializer, and connected the application to a MySQL database via MySQL Workbench. For API testing and validation, we used Postman.

The system is structured into three major modules based on user roles:

Super Admin Panel

Customer Panel

Delivery Boy Panel

This is a Role-Based Access (RBA) system, where each module is designed with specific responsibilities and access levels.

In the Super Admin Panel, the admin can manage roles, authenticate users, and perform full CRUD operations on categories, subcategories, hotel outlets (based on pin codes), offers, and coupons. We implemented @ManyToOne relationships in both the backend and React frontend using map functions for dynamic dropdowns. Admins can also add and manage products, including setting strike prices, display prices, and associating products with respective subcategories and hotel outlets. Additionally, the panel supports management of customer and delivery boy records, including personal details, document uploads, and expense tracking.

The Customer Panel supports browsing menus, placing food orders, and selecting from multiple payment methods such as UPI, cash on delivery, and online payments. Once an order is placed, an OTP verification process ensures secure delivery. The system ensures that customers receive home-style food within 20 minutes.

In the Delivery Boy Panel, delivery agents can view assigned orders, accept deliveries, generate bills, verify OTPs upon delivery, and collect payments. The panel also includes performance tracking, delivery ratings, and a helpdesk for issue resolution.

This project gave me hands-on experience in building scalable, secure, and user-centric applications using modern frontend and backend technologies, along with integrating real-time data operations and role-based security architecture.”
